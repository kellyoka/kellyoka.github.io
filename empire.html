How this code is organized (for modding)

Everything lives in one script, split into labelled sections. Start with CONFIG (map size, land fraction, city count, capture chance) and UNIT_TYPES (moves, hit points, strength, build time, fuel, capacity). Adding a unit type there makes it buildable automatically.

Rules are in classify() (what happens when a unit tries to enter a tile), doMove(), combat() and startTurn(). Map generation is genMap() and placeCities(). The computer opponent is aiTurn() with one function per unit role. It currently sees the whole map, which is the first thing to change for a fairer game.

Open the browser console and type G to inspect the live game state. The game autosaves at the start of each of your turns in this browser.
